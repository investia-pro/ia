# InvestIA PRO

Plataforma Inteligente para Análise de Investimentos.

## Objetivo

Desenvolver um sistema capaz de analisar automaticamente:

- Ações da B3
- Ações Americanas
- ETFs
- FIIs
- Criptomoedas

Gerando recomendações baseadas em indicadores técnicos, fundamentos, notícias e Inteligência Artificial.
